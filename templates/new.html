How to create a GitHub token
  1. Open GitHub Settings → Developer settings → Personal access tokens.
  2. Create a fine-grained token and select the repository.
  3. Grant read-only access to Metadata and whichever of Issues, Pull requests, and Contents you plan to sync.
  4. For Stargazers, the token owner must be an admin or collaborator. GitHub currently requires Administration: Read and write on a fine-grained token.
  5. Generate the token and copy it here. GitHub only shows it once.
